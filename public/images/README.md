# Фотографии сайта

Сюда кладутся **настоящие** фотографии лицея, учеников, занятий и
преподавателей. Стоковые и сгенерированные изображения не используются.

Пока файла нет, сайт автоматически показывает заглушку с подписью, какой кадр
нужен. Как только файл с нужным именем появляется в этой папке, он
подставляется автоматически (перезапуск сборки не требуется).

## Требуемые файлы

| Файл | Кадр | Пропорции |
| --- | --- | --- |
| `hero.jpg` | Главный экран: здание лицея или ученики. Минимум 2400px по ширине | 16:9 |
| `about-main.jpg` | Секция «О лицее», вертикальный кадр | 4:5 |
| `about-01.jpg` … `about-04.jpg` | Карусель: занятие, ученики, лаборатория, здание | 16:10 |
| `life-01.jpg` … `life-03.jpg` | Полноширинные кадры: занятие, лаборатория, мероприятие | 21:9 |
| `direction-economics.jpg`, `direction-technology.jpg`, `direction-finance.jpg`, `direction-it.jpg` | Карточки направлений | 4:3 |
| `direction-*-hero.jpg` | Обложки страниц направлений | 21:9 |
| `teacher-01.jpg` … `teacher-08.jpg` | Портреты преподавателей, прямоугольный кадр | 3:4 |
| `news-01.jpg` … `news-06.jpg` | Иллюстрации к новостям | 16:9 / 4:3 |
| `logo.svg` или `logo.png` | Официальный логотип (необязательно) | квадрат |

## Рекомендации

- Формат: JPG (или WebP) с качеством 80–85.
- Ширина: 2400px для полноширинных кадров, 1600px для карточек, 900px для
  портретов преподавателей.
- Вес файла желательно до 400 КБ.
- Съёмка при естественном свете, без тяжёлых фильтров и рамок.
